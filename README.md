🎨 Hand Art
A gesture-based drawing application that uses your webcam to track hand movements and draw on a digital canvas.

✨ Features
☝️ Draw using your index finger
✌️ Change drawing color using gestures
🖐️ Open palm to pause
✊ Closed fist to stop drawing
🎨 Multiple brush colors
🖌️ Adjustable brush size
🧹 Clear canvas
🎯 Real-time hand tracking and gesture detection
🛠️ Technologies Used
React
TypeScript
Tailwind CSS
Vite
MediaPipe Hand Landmarker
HTML Canvas API
Webcam API
